Local LLMs on Apple Silicon.
Zero token cost.

brokemode runs, benchmarks, and monitors local models on a 16GB MacBook — and speaks the Anthropic Messages API, so Claude Code runs against your own machine instead of a metered endpoint.

Background

API tokens cost money; the M-series GPU you already own does not. A MacBook Pro M2 with 16GB of unified memory decodes a 9B-parameter model at around 20 tokens per second — enough for chat, summarization, code review, and agentic tool-calling, at a marginal cost of exactly zero. Hence the name: this is the mode you switch to when you're broke (or just refuse to pay per token to think).

The catch is that 16GB is a hard ceiling shared with macOS itself, and the line between "runs great" and "swap-death" is only a couple of gigabytes wide. brokemode exists to hold that line:

A budget, enforced everywhere

models.yaml carries measured peak RSS per model and a global max_rss_gb: 11 budget. The installer, the CLI, and the gateway all refuse to pull or load anything that exceeds it — loudly, with the exact numbers, never silently.

Honest benchmarks

brokemode bench derives TTFT, prefill, and decode rates from Ollama's native timing fields over 3 warmup + 5 measured runs and reports median and p95, never the mean — while sampling GPU residency, memory pressure, RSS, and thermal state at 1Hz so you know why a number moved.

Claude Code as the client

brokemode gateway implements the Anthropic Messages API surface Claude Code requires — the exact SSE event sequence, tool-use round trips, model discovery — translated onto Ollama, with every request instrumented (TTFT, tok/s, tokens, peak RSS).

What it is

  • One static Go binary (CGO_ENABLED=0) with the web dashboard, model registry, and benchmark prompts embedded — a release download is fully self-contained.
  • An opinionated model registry for a 16GB box: what to run, at what context length, and what it will actually cost in resident memory.
  • A benchmark harness, a terminal dashboard, a web dashboard with a 1Hz live telemetry stream, Prometheus metrics, and an importable Grafana dashboard.
  • No Docker, no cloud dependencies, no Python. Shell only for the installer.

What it is not

A 9B model at Q4 is not Sonnet, and nothing here pretends otherwise. The premise is different: for a large slice of daily work, a free, private, always-available local model is good enough — and when it isn't, you've lost nothing by trying it first.
