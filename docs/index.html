Overview

Why this exists.

API tokens cost money; the M-series GPU you already own does not. A MacBook Pro M2 with 16GB of unified memory decodes a 9B-parameter model at around 20 tokens per second — enough for chat, summarization, code review, and agentic tool-calling, at a marginal cost of exactly zero. Hence the name: this is the mode you switch to when you're broke, or just refuse to pay per token to think.

The catch is that 16GB is a hard ceiling shared with macOS itself, and the line between "runs great" and "swap-death" is only a couple of gigabytes wide. brokemode exists to hold that line.

What's in the box

One static binary. Everything included.

The web dashboard, model registry, and benchmark prompts are compiled in via embed.FS — a release download is one fully self-contained file. No Docker, no cloud, no Python.

▦

A budget, enforced everywhere

models.yaml carries measured peak RSS per model and a global 11GB budget. Installer, CLI, and gateway all refuse anything over it — loudly, with exact numbers.

◔

Honest benchmarks

TTFT, prefill, and decode rates from Ollama's native timing fields; 3 warmup + 5 measured runs; median and p95, never the mean.

⇄

Claude Code gateway

The Anthropic Messages API surface Claude Code requires — exact SSE sequence, tool-use round trips, model discovery — translated onto Ollama.

♒

1Hz host telemetry

GPU residency and package power, memory pressure, wired/compressed pages, runner RSS, and thermal state sampled every second during runs.

⌗

Machine-aware doctor

Classifies every model as comfortable, tight, or no-fit for your actual machine, recommends a pick, and says exactly how many GB to free.

◧

Dashboards everywhere

A bubbletea TUI, an embedded React dashboard fed by a 1Hz SSE stream, Prometheus metrics, and an importable Grafana dashboard.

Expectations

What it is not.

A 9B model at Q4 is not Sonnet, and nothing here pretends otherwise. The premise is different: for a large slice of daily work, a free, private, always-available local model is good enough — and when it isn't, you've lost nothing by trying it first.
