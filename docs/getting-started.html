Getting started

One line on the Mac itself. Everything else follows from there.

Requirements

  • Apple Silicon Mac (arm64) — the installer refuses anything else
  • 16GB unified memory recommended; 8–16GB works with a tightened budget and loud warnings
  • Homebrew
  • ~10GB free disk for the default models (checked before pulling, with the exact shortfall reported)

Install

curl -fsSL https://raw.githubusercontent.com/alileza/brokemode/main/install.sh | bash

To pass flags through the pipe, use bash -s --:

# preview without changing anything
curl -fsSL https://raw.githubusercontent.com/alileza/brokemode/main/install.sh | bash -s -- --dry-run

# pull only specific models
curl -fsSL https://raw.githubusercontent.com/alileza/brokemode/main/install.sh | bash -s -- --models qwen3.5:4b,gemma4:e4b

Or from a clone (builds with Go instead of downloading a release — use this if no release is published yet): 

git clone https://github.com/alileza/brokemode.git && cd brokemode && ./install.sh

The installer is idempotent — re-running is always safe. It:

  1. verifies arm64 macOS and checks memory, cores, and free disk, warning with exact GB figures if anything is short;
  2. brew-installs ollama + jq if missing and starts Ollama via brew services;
  3. downloads one self-contained binary matched to your machine (registry, dashboard, and prompts embedded) and smoke-tests it;
  4. pulls every default model that fits your machine's budget — and prints a fit table with a recommended pick.

First steps

# enable the environment (once)
grep -q 'brokemode/env' ~/.zshrc || echo 'source ~/.brokemode/env' >> ~/.zshrc
source ~/.brokemode/env

# what can THIS machine run?
brokemode doctor

# benchmark the recommended model (median/p95, results/summary.md)
brokemode bench --model qwen3.5:9b

# gateway :9100 + web dashboard http://127.0.0.1:9101
brokemode serve

# terminal dashboard
brokemode tui

For full GPU and power telemetry during benchmarks, run sudo -v first — powermetrics needs root. Without it the run still completes but is loudly marked PARTIAL.

Point Claude Code at it

brokemode serve          # keep running

# in another terminal (already set if you sourced ~/.brokemode/env)
export ANTHROPIC_BASE_URL=http://127.0.0.1:9100
export ANTHROPIC_AUTH_TOKEN=brokemode-local   # any non-empty token
claude

Model names alias through the registry: requests for claude-sonnet-5 (dated variants included) run on qwen3.5:9b, claude-haiku-4-5 on qwen3.5:4b — each with its registry context length applied. Verify a running gateway any time with ./scripts/verify-gateway.sh.

If something's off

SymptomFix
"no release binary published yet" Clone and ./install.sh — it builds with Go.
"is ollama running?" brew services start ollama, confirm with ollama list.
"NOT ENOUGH DISK" / "REFUSING to pull" The message names the exact GB to free. ollama rm <model> reclaims blob space; re-check with brokemode doctor.
Slow, fans on Check brokemode tui — thermal THROTTLED or red memory pressure means close apps or let it cool.
Uninstall rm -rf ~/.brokemode, drop the zshrc line, optionally brew services stop ollama.
