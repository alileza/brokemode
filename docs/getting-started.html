One line on the Mac itself

Getting started.

Install, check what your machine can run, benchmark it, then point Claude Code at it. Everything else follows from there.

Before you start

Requirements.

RequirementNotes
Apple Silicon Mac (arm64) The installer refuses anything else, including Rosetta shells.
16GB unified memory Recommended. 8–16GB works with a tightened budget and loud warnings; below 8GB nothing in the registry fits.
Homebrew brew.sh — used to install and run Ollama as a service. The registry declares a minimum Ollama version; if yours is older the installer offers the upgrade and restarts the daemon so client and server match.
~10GB free disk For the default models. Checked before pulling — the exact shortfall is reported if you're low.
Install

One line.

Idempotent — re-running is always safe. It verifies the machine, installs Ollama, downloads one self-contained binary matched to your architecture, pulls the models that fit, and prints a fit table with a recommended pick.

$ curl -fsSL https://raw.githubusercontent.com/alileza/brokemode/main/install.sh | bash # preview without changing anything $ curl -fsSL https://raw.githubusercontent.com/alileza/brokemode/main/install.sh | bash -s -- --dry-run # pull only specific models $ curl -fsSL https://raw.githubusercontent.com/alileza/brokemode/main/install.sh | bash -s -- --models qwen3.5:4b,gemma4:e4b # or from a clone (builds with Go — use this if no release is published yet) $ git clone https://github.com/alileza/brokemode.git && cd brokemode && ./install.sh
First steps

Doctor, bench, serve.

# the installer already put brokemode on PATH and wired new terminals; # only the terminal you installed from needs this once: $ source ~/.brokemode/env # what can THIS machine run? $ brokemode doctor # benchmark the recommended model (median/p95 into results/summary.md) $ brokemode bench --model qwen3.5:9b # gateway :9100 + web dashboard http://127.0.0.1:9101 $ brokemode serve # terminal dashboard $ brokemode tui

For full GPU and power telemetry during benchmarks, run sudo -v first — powermetrics needs root. Without it the run still completes but is loudly marked PARTIAL.

The payoff

Point Claude Code at it.

The gateway accepts any non-empty token and aliases Claude model names through the registry — requests for claude-sonnet-5 run on qwen3.5:9b, claude-haiku-4-5 on qwen3.5:4b, each with its registry context length applied.

$ brokemode serve # keep running # in another terminal (already set if you sourced ~/.brokemode/env) $ export ANTHROPIC_BASE_URL=http://127.0.0.1:9100 $ export ANTHROPIC_AUTH_TOKEN=brokemode-local $ claude # verify a running gateway any time $ ./scripts/verify-gateway.sh
If something's off

Troubleshooting.

SymptomFix
"no release binary published yet" Clone and ./install.sh — it builds with Go (brew install go if needed).
"is ollama running?" brew services start ollama, then confirm with ollama list.
"ollama server vX is older than required vY" Re-run the installer (it offers the upgrade), or brew upgrade ollama && brew services restart ollama — the restart matters, or the stale daemon keeps answering.
"pull model manifest: 412 … requires a newer version of Ollama" The model registry refused the pull. The installer catches this, offers the upgrade, and retries; if brew's bottle still lags, install the latest from ollama.com/download and re-run.
Claude Code: "issue with the selected model" It's asking for a model id the gateway doesn't alias. Run /model inside Claude Code and pick claude-sonnet-5 — or rely on the env file, which presets ANTHROPIC_MODEL to it.
"NOT ENOUGH DISK" / "REFUSING to pull" The message names the exact GB to free. ollama rm <model> reclaims blob space; re-check with brokemode doctor.
Slow, fans on Check brokemode tui — thermal THROTTLED or red memory pressure means close apps or let it cool. Bench results during throttle carry a warning.
Uninstall rm -rf ~/.brokemode, drop the zshrc line, optionally brew services stop ollama (model blobs live in ~/.ollama).
